# Which tool is right for me?

| Task | Start with |
|---|---|
| Try models and compare results in a browser | [AI Playground](https://picsart.com/ai-playground/) |
| Generate or edit media inside an AI conversation | [MCP](/guide/mcp-quickstart) |
| Give an agent reusable workflow instructions | [Skills](/guide/skills), with working tools or CLI access |
| Run terminal commands, scripts, or batches | [CLI](/guide/cli-quickstart) |
| Add generation to a Node.js application | [TypeScript SDK](/guide/sdk) |
| Call Picsart from another programming language | [REST API](/guide/rest-api) |

Skills and MCP serve different purposes: skills describe how to work, while MCP connects an agent to tools. A skill can use MCP, the CLI, or both. Either execution path can support cost checks and multi-step work if the agent has the necessary commands or tools.

You can combine interfaces, but check model availability and parameters in each installed or connected version. A CLI sign-in does not authenticate a hosted MCP connection or your application's API client. See [Authentication](/guide/authentication).
